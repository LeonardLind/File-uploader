# File: frontend/src/components/HighlightEditorModal.tsx

- [ ] Read and understand this file

What it is:
- Full-screen modal to create or edit a highlight clip.

What it does (easy words):
- Loads the original video.
- Lets you choose start/end times and a thumbnail frame.
- Records a trimmed clip with MediaRecorder.
- Uploads the new highlight video + thumbnail.

Practical example:
- You set start at 2.0s and end at 6.0s, then save. It uploads a 4s highlight clip.
