# File: frontend/src/components/ConfirmDialog.tsx

- [ ] Read and understand this file

What it is:
- A small confirmation modal.

What it does (easy words):
- Shows a dialog when `open` is true.
- Calls `onConfirm` or `onCancel`.
- Can look red for dangerous actions.

Practical example:
- When you click Delete, this pops up and asks "Are you sure?".
