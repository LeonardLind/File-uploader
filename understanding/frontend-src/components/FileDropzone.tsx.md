# File: frontend/src/components/FileDropzone.tsx

- [ ] Read and understand this file

What it is:
- Drag-and-drop area for adding files.

What it does (easy words):
- Accepts videos and images.
- If the file is AVI, it converts to MP4 in the browser.
- Adds files to the global store and shows progress.

Practical example:
- You drop 3 files and 1 is AVI. It converts the AVI, then all files appear in the upload list.
