# File: frontend/src/vite-env.d.ts

- [ ] Read and understand this file

What it is:
- Vite type helpers for TypeScript.

What it does (easy words):
- Tells TypeScript about Vite globals like `import.meta.env`.

Practical example:
- Without this, `import.meta.env.VITE_API_URL` would show TypeScript errors.
